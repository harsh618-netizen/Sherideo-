# Sherideo 🎬

**Sherideo** is an Android video-sharing app project built with MIT App Inventor.

## 📱 Download Sherideo

The Android APK should be published in the **Releases** section of this repository.

➡️ **[Open Sherideo Releases](https://github.com/harsh618-netizen/Sherideo-/releases)**

If no release is available yet, the APK has not been attached to a release. Please check back later.

## ✨ Project

- **App name:** Sherideo
- **Platform:** Android
- **Builder:** MIT App Inventor
- **Category:** Video sharing

## 📥 Installation

1. Open the Releases page linked above.
2. Download the latest Sherideo `.apk` file.
3. Open the downloaded APK on your Android device.
4. If Android asks, allow installation from that source, then continue installing.

**Safety note:** Only install APKs from a source you trust. Android may show a warning for apps installed outside Google Play.
